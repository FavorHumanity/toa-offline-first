What it is

A small demo that runs in your browser with no internet. It shows a digital ID wallet, a limits table and a ledger that flags edits, all working on the device first.

Open the demo

Four preventive items it shows

  • Offline operation, with no network calls.
  • A SHA-256 hash-chained ledger.
  • A chain check that flags the first broken block, plus a signature check if the browser supports it.
  • Tiered limits that block over-limit transfers. These are our own proposed internal limits, not limits set by law.

What it is not

It is not finished software, it has not been audited, and it is not connected to any bank or national system. Everything resets when the page is reloaded.
